# Offer One-Pager

## Offer Name
14-Day Lead Reactivation Sprint + AI Booking Assistant

## Ideal Client Profile
- Med spas and dental clinics
- Running paid or organic lead flow
- Missing callbacks/follow-up with older leads
- No consistent reactivation process

## Problem
Clinics are paying for lead generation but lose booked revenue because:
- old leads are never re-contacted
- response speed is inconsistent
- booking handoff is manual and delayed

## Outcome
Within 14 days, implement a repeatable reactivation system that:
- contacts old leads with personalized outreach
- triages responses into hot/warm/cold buckets
- pushes hot intent to booking links fast
- gives owner a live pipeline view in Sheets

## Deliverables
- Data model + pipeline in Google Sheets
- Outreach + follow-up automation via Apps Script
- Reply classification and suppression logic
- Stripe payment webhook ingestion
- Onboarding task automation and daily digest

- Start fee: $1,050 (70% deposit)
- Optional maintenance: $300/mo

## Guarantee Terms
- Build and deploy core pipeline in 14 days
- If implementation is not delivered as scoped, refund implementation fee
- Revenue outcomes depend on list quality, existing demand, and client execution
