# Sales Call Script (15 Minutes)

## 0) Agenda (30s)
"I will ask a few questions about lead flow and follow-up, then walk you through a 14-day implementation and next steps."

## 1) Diagnose (4 min)
Ask:
- "How many inbound leads do you get each month?"
- "What percentage gets contacted within 5 minutes?"
- "How many older leads are still sitting in your CRM?"
- "Who currently owns follow-up and booking?"

## 2) Quantify Loss (3 min)
Use rough math:
- Missed contacts x estimated booking rate x average ticket
- Confirm pain using their own numbers

## 3) Present Single Offer (3 min)
"We run a 14-day lead reactivation sprint and booking assistant. You get pipeline setup, automated outreach/follow-up, reply triage, and payment/onboarding automation."

## 4) Price + Close (2 min)
"Setup is $1,500. To start this week, deposit is $1,050 today."

## 5) Objection Handling (2 min)
If price objection:
- keep scope fixed
- offer split structure only if needed
- still collect first installment on call

## 6) Final CTA
"If you are ready, here is the secure deposit link now. Once paid, onboarding form is sent immediately and build starts today."

## Rules
- Start with diagnosis and revenue loss
- Present one package only
- Ask for payment on call
- No fake case studies or inflated claims
